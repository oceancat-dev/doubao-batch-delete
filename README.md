# 豆包聊天记录批量删除

豆包网页版目前没有提供聊天记录批量删除功能。本项目是一个本地 Chrome / Edge 扩展，可先批量选择会话，再通过豆包网页现有的“更多 → 删除 → 确认”流程逐条执行。

## 功能

- 扫描当前已经加载的聊天记录
- 自动滚动侧边栏，继续加载历史记录
- 单选、全选和清空选择
- 删除前列出待删除记录，并要求输入 `确认删除`
- 按顺序逐条删除，避免同时操作多个菜单
- 支持中途停止；失败记录会保留并在控制台输出原因
- 不读取 Cookie，不上传聊天内容，也不调用豆包未公开接口

## 安装

1. 从 [Releases](https://github.com/youyang13811808-code/doubao-batch-delete/releases) 下载最新的 `doubao-batch-delete-v*.zip` 并解压。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择刚解压的目录（目录内应直接包含 `manifest.json`）。
5. 登录 [豆包网页版](https://www.doubao.com/chat/) 并刷新页面。

> Chrome / Edge 会限制未经扩展商店签名的扩展直接安装，因此 ZIP 发布包需要先解压，再通过开发者模式加载。

## 使用

1. 右上角会出现“批量管理”面板。
2. 点“加载全部”，等待历史记录滚动加载完成。
3. 勾选需要删除的会话，或点击“全选”。
4. 点“删除所选”，核对记录并按提示输入 `确认删除`。
5. 扩展逐条删除。可随时点“停止任务”；已经删除的记录无法恢复。

## 项目文件

- `manifest.json`：Chrome Manifest V3 扩展配置
- `content.js`：会话识别、选择和删除流程
- `styles.css`：批量管理面板样式

## 注意

- 仅支持 `doubao.com` 网页版；豆包桌面客户端不支持安装浏览器扩展。
- 建议先选 1 条不重要的会话试运行。
- 删除期间不要切换页面、折叠侧栏或手动操作会话菜单。
- 豆包页面改版后，可能需要更新元素识别规则。失败项会保留选择，并在浏览器控制台输出原因。
- 本工具不包含“删除记忆”功能，记忆与聊天记录是两类数据。
- 本项目与豆包及字节跳动没有关联，是非官方辅助工具。
