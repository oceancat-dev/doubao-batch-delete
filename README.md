# 豆包聊天记录批量删除

这是一个本地 Chrome / Edge 扩展，通过豆包网页现有的“更多 → 删除 → 确认”界面逐条执行，不读取 Cookie，也不调用豆包未公开接口。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `D:\DoubaoBatchDelete`。
5. 登录 [豆包网页版](https://www.doubao.com/chat/) 并刷新页面。

## 使用

1. 右上角会出现“批量管理”面板。
2. 点“加载全部”，等待历史记录滚动加载完成。
3. 勾选需要删除的会话，或点击“全选”。
4. 点“删除所选”，核对记录并按提示输入 `确认删除`。
5. 扩展逐条删除。可随时点“停止任务”；已经删除的记录无法恢复。

## 注意

- 仅支持 `doubao.com` 网页版；豆包桌面客户端不支持安装浏览器扩展。
- 建议先选 1 条不重要的会话试运行。
- 删除期间不要切换页面、折叠侧栏或手动操作会话菜单。
- 豆包页面改版后，可能需要更新元素识别规则。失败项会保留选择，并在浏览器控制台输出原因。
- 本工具不包含“删除记忆”功能，记忆与聊天记录是两类数据。
